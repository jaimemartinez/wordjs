# Badge fonts

The badge designer's typefaces (conference-manager 2.29.0). Each `<id>-<weight>.js` module exports one
**unmodified** TrueType file as base64 — a module, so the plugin loads it with `require` and needs no
filesystem permission. The same bytes are sent to the browser (the designer, the credential page) and
embedded in the badge PDFs.

All are licensed under the SIL Open Font License, Version 1.1 (`OFL.txt`). The files come from Google Fonts
(static instances), except Lato, Oswald and Poppins (the same projects' static releases).
